# Getting Started

## Prerequisites

- **Flutter SDK** — version pinned in `pubspec.yaml` (`environment.sdk`)
- **Dart SDK** — bundled with Flutter
- **Node.js** — for Cloud Functions in `functions/`
- **Firebase CLI** — `npm install -g firebase-tools`
- **Git**
- A modern Chrome browser (this project targets Flutter Web)

## 1. Clone

```bash
git clone https://github.com/kazubazoo/SMARTFACTORY365-DEMO.git
cd SMARTFACTORY365-DEMO
```

## 2. Install Flutter dependencies

```bash
flutter pub get
```

## 3. Configure Firebase

The project uses Firebase Auth + Firestore + Cloud Functions. You'll need:

- A Firebase project (or access to the existing one)
- `lib/firebase_options.dart` generated by `flutterfire configure` (already
  committed for the dev project)
- Service account credentials for any local function testing

## 4. Run locally (web)

```bash
flutter run -d chrome
```

The app launches in Chrome. Login page is the entry point (see
[login-and-sessions.md](login-and-sessions.md)).

## 5. Cloud Functions (optional, only when working on backend)

```bash
cd functions
npm install
firebase emulators:start --only functions
```

## 6. Build for production

```bash
flutter build web --release
```

Output goes to `build/web/`. Deploy with `firebase deploy --only hosting`.

## Common pitfalls

- **`flutter pub get` fails**: check the Flutter SDK version matches
  `pubspec.yaml`'s `environment.sdk`
- **Firebase auth errors on first run**: make sure the dev Firebase project
  has your test user created and the email/password provider enabled
- **Web build is huge / slow**: this is normal for Flutter Web. Use
  `--release` for production builds
