# Architecture

## Tech stack

| Layer        | Technology                                       |
| ------------ | ------------------------------------------------ |
| UI framework | Flutter (Web target)                             |
| UI scaffold  | FlutterFlow-generated code                       |
| State        | FlutterFlow models + Cubits (`flutter_bloc`)     |
| Routing      | GoRouter (`lib/flutter_flow/nav/nav.dart`)       |
| Auth         | Firebase Auth (email/password)                   |
| Database     | Cloud Firestore                                  |
| Backend API  | Firebase Cloud Functions (`functions/`, Node.js) |
| Hosting      | Firebase Hosting                                 |
| Local prefs  | `shared_preferences` + `localStorage` wrapper    |

```
       ▲                                        └──────┬───────┘
       │                                               │

       └────────────│ User action     │◀───────────────┘
                    │ (button, form)  │
                    └─────────────────┘
```

Most screens are `StatefulWidget` + a paired `Model` class generated by
FlutterFlow. State that needs to persist across rebuilds (controllers, focus
nodes, fetched data) lives on the model.

## Auth flow

1. User submits credentials on the login page
2. `_login()` in `login_page_widget.dart`:
   - Signs out any existing Firebase session
   - Calls `authManager.signInWithEmail(...)` (`firebase_auth_manager.dart`)
   - Checks `account_status/{uid}` for the disabled flag
   - Checks `presence/{uid}` for an active session (single-session enforcement)
   - Routes to `EquipmentOverview` on success
3. After successful navigation, `nav.dart` calls `UserPresence.goOnline(uid)`
   which writes to `presence/{uid}` and starts a 30s heartbeat
4. On logout (side nav button) `UserPresence.goOffline(uid)` clears the
   presence doc and the heartbeat timer

See [login-and-sessions.md](login-and-sessions.md) for full detail.

## Routing

All routes are declared in `lib/flutter_flow/nav/nav.dart`. The app uses
`GoRouter` with `goNamedAuth` for auth-aware navigation that automatically
redirects unauthenticated users to the login page.

## Theming

`FlutterFlowTheme.of(context)` exposes the active color palette. Key colors
referenced throughout the codebase:

- `theme.primary` — main brand color (used by cyberpunk toast glow)
- `theme.tertiary` — accent gradient color (purple — avoid for new features
  unless intentional)
- `theme.primaryBackground`, `theme.secondaryBackground`
- `theme.primaryText`, `theme.secondaryText`, `theme.alternate`

## Persistence layers

| Layer                   | Where                  | Used for                          |
| ----------------------- | ---------------------- | --------------------------------- |
| Firebase Auth           | server                 | login session, JWT                |
| Firestore               | server                 | all app data + presence + roles   |
| `SessionStorage`        | browser localStorage   | per-user role/modules cache       |
| `shared_preferences`    | browser localStorage   | "Remember Me" email/password      |
| FlutterFlow models      | in-memory              | controllers, fetched docs         |
